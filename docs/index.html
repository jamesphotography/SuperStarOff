使用教程

详细的图文教程，帮助你快速上手

1 在 Photoshop 中打开图片

在 Photoshop 中打开需要处理的星空摄影作品。支持 TIFF (8-bit/16-bit)、JPG、PNG、PSD 等格式。

2 调用 SuperStarOff 插件

点击菜单：文件 → 脚本 → SuperStarOff，选择你的 Photoshop 版本（支持 PS 2019-2026）。

3 等待 AI 处理完成

插件会自动处理当前图层，处理时间取决于图像大小（通常几秒到几分钟）。原图层保持不变，方便对比效果。

常见问题

SuperStarOff 是免费的吗？

是的，SuperStarOff 目前完全免费供个人和非商业用途使用。

支持 Windows 系统吗？

目前仅支持 macOS 系统。Windows 版本在计划中，敬请期待。

可以批量处理图片吗？

批量处理功能计划在 V1.1 版本中推出。

支持 FITS 格式吗？

FITS 格式支持计划在 V1.1 版本中添加。

为什么首次运行会有安全提示？

这是 macOS 的正常安全机制。请右键点击应用图标选择"打开"，在弹出对话框中点击"打开"即可。
