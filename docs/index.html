使用指南

3步轻松去除星点

01

加载图片

将图片拖放到窗口，或点击"打开图片"按钮选择文件

支持格式：TIFF (8-bit/16-bit)、JPG、PNG
02

选择参数

选择处理步长和设备（推荐使用默认设置）

参数建议：
  • 步长 256 - 日常使用，平衡速度与质量
  • 步长 128 - 精细处理，最佳质量
  • 步长 512 - 快速预览
03

处理并保存

点击"去除星点"，等待处理完成，保存结果

提示：可以在预览窗口中对比原图和处理后的效果

常见问题

SuperStarOff 是免费的吗？

是的，SuperStarOff 目前完全免费供个人和非商业用途使用。

支持 Windows 系统吗？

目前仅支持 macOS 系统。Windows 版本在计划中，敬请期待。

可以批量处理图片吗？

批量处理功能计划在 V1.1 版本中推出。

支持 FITS 格式吗？

FITS 格式支持计划在 V1.1 版本中添加。

为什么首次运行会有安全提示？

这是 macOS 的正常安全机制。请右键点击应用图标选择"打开"，在弹出对话框中点击"打开"即可。

如何获取技术支持？
